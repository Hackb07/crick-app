## 📝 User Questions Answered

### "What is a prototype?"
**Answer**: An interactive mockup that simulates the final product without full backend functionality. See `GLOSSARY.md` under "Project Types" for complete definition.

**Characteristics**:
- ✅ Interactive UI (clickable, navigable)
- ✅ Visual design matches final product
- ❌ No real data processing
- ❌ No backend integration (uses mock data)

**Tools**: Figma, Framer, ProtoPie, Adobe XD

**Use Cases**: User testing, stakeholder presentations, developer handoff
