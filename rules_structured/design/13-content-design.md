# Content Design & Micro-copy

**Category**: Design
**Priority**: P2
**Shorthand**: `@design:content`

---

## 🎯 Purpose

Ensure clear, concise, and helpful text across the user interface. "Words are part of the design."

---

## 📋 Rules

### Rule 1: Error Messages

**Bad** ❌:
- "Error 500"
- "An error has occurred."
- "Failed."

**Good** ✅:
- **State problem**: "We couldn't save your changes."
- **Explain why**: "Your internet connection was lost."
- **Offer solution**: "Check your connection and [Try Again]."

### Rule 2: Empty States

**Bad** ❌:
- Blank white screen.
- "No data."

**Good** ✅:
- **Illustration**: Friendly image/icon representing the missing content.
- **Context**: "You haven't added any tasks yet."
- **Call to Action**: "[Create First Task]" button.

### Rule 3: Button Labels

**Bad** ❌:
- "Click Here"
- "Yes" / "No" (in vague modals)
- "Submit" (generic)

**Good** ✅:
- **Action + Object**: "Save Profile", "Delete Post", "Create Account".
- **Specific**: "Yes, Delete It" vs "Cancel".

### Rule 4: Tone and Voice

- **Clear**: Avoid jargon. Use simple words.
- **Concise**: Cut fluff. Get to the point.
- **Human**: Use "We couldn't find..." instead of "404 Not Found".

---

## ✅ Content Checklist

- [ ] Are error messages helpful and actionable?
- [ ] Do empty states encourage action?
- [ ] Are buttons descriptive Action + Object?
- [ ] Is jargon removed?
- [ ] is inclusivity considered (They/Them vs He/She)?
