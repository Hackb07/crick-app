## 🚀 Quick Start Guide

### For New Projects
```bash
1. Read @design:principles (Core UI/UX)
2. Set up @design:tokens (Design system foundation)
3. Choose platform: @design:responsive OR @design:pwa
4. Build @design:components (Component library)
5. Add @design:animation (Micro-interactions)
```

### For Existing Projects
```bash
1. Audit current design against @design:principles
2. Implement @design:tokens (Centralize styling)
3. Refactor components using @design:components
4. Add responsive breakpoints (@design:responsive)
5. Optimize forms (@design:forms)
```

### For Landing Pages
```bash
1. Follow @design:landing (AIDA structure)
2. Optimize performance (Core Web Vitals)
3. Implement @design:forms (Lead capture)
4. Add @design:animation (Engagement)
```

### For Prototypes
```bash
1. Use @design:principles (Visual consistency)
2. Apply @design:workflow (Design-to-code handoff)
3. Build @design:components (Reusable elements)
4. Test @design:responsive (All screen sizes)
```

## 🎨 Builder.io Philosophy Integration

The design rules are inspired by **Builder.io's visual development approach**:

### Visual-First Development
✅ What you see is what you get (WYSIWYG)  
✅ Component-driven architecture  
✅ Design tokens for consistency  
✅ Visual editors for non-technical users  

### Performance by Default
✅ Code splitting and lazy loading  
✅ Image optimization (WebP, srcset)  
✅ Critical CSS inlining  
✅ Core Web Vitals targets  

### Accessibility First
✅ WCAG AA minimum compliance  
✅ Semantic HTML structure  
✅ Keyboard navigation support  
✅ Screen reader compatibility

## 📊 Success Metrics

### Performance Targets
- **Lighthouse Score**: 90+ (all categories)
- **LCP**: < 2.5s (Largest Contentful Paint)
- **FID**: < 100ms (First Input Delay)
- **CLS**: < 0.1 (Cumulative Layout Shift)
- **Bundle Size**: < 200KB initial JS (gzipped)

### Accessibility Targets
- **WCAG Compliance**: AA minimum (AAA for critical paths)
- **Contrast Ratio**: 4.5:1 minimum for normal text
- **Keyboard Navigation**: 100% functional without mouse
- **Screen Reader**: Full NVDA/JAWS/VoiceOver compatibility

### User Experience Targets
- **Form Completion**: 80%+ completion rate
- **Mobile Usability**: 0 issues (Google Search Console)
- **Cross-browser**: Consistent on Chrome, Firefox, Safari, Edge
- **Responsive**: Works on all breakpoints (sm to 2xl)
