# Landing Page Optimization

## 1. Structure (AIDA Model)
- **Attention (Hero Section)**: Strong Headline + Subheadline + Primary CTA. High quality visual.
- **Interest (Features/Benefits)**: "What's in it for me?" - Focus on benefits, not just features.
- **Desire (Social Proof)**: Testimonials, generic logos, case studies.
- **Action (Closing)**: Final strong call to action.

## 2. Performance (Vital for LP)
- **Core Web Vitals**: Focus on LCP (Largest Contentful Paint) < 2.5s.
- **Image Optimization**: Serve specific sizes for mobile vs desktop (`srcset`).
- **Critical CSS**: Inline critical styles for "above the fold" content to reduce render blocking.

## 3. Conversion Design
- **Directional Cues**: Use arrows or gaze (people looking at the button) to guide user eyes to the CTA.
- **Form Design**: Minimal fields. Remove friction.
- **Clear Value Prop**: Ensure the user understands *exactly* what is offered within 5 seconds.
